# NexusPanel User Documentation

Portal source for docs.nexuspanel.io (tooling: Docusaurus, wired at P1 — gap G-07).
Every user-visible feature lands **together with** its page here and with
regenerated screenshots from the demo environment (gap G-08).

## Information architecture

- **Getting started** — requirements · cloud-init quick install · setup wizard · first login + 2FA
- **Admin guide** — accounts & packages · resellers & branding · sites & PHP · SSL ·
  email (relay, DKIM) · DNS & DNSSEC · databases · files, FTP & SSH ·
  firewall, fail2ban, WAF & malware · backups & restore · apps, Git & staging ·
  nodes & services · config engine & drift · audit & verification · migrations ·
  extensions · webhooks · notifications · panel updates
- **Account holder guide** — my sites · my mail · my databases · my files · my backups
- **API & CLI** — OpenAPI reference · `nexus` cookbook · token scoping
- **Troubleshooting** — login & access · mail delivery · DNS propagation ·
  certificate renewal · backup failures · agent & drift alerts
- **Runbooks** — suspected account compromise · agent compromise · master-key rotation

## Screenshot rig (from P1)

Playwright drives the demo environment with deterministic seed data; every image is
checked into `static/screenshots/<version>/` and regenerated by CI on UI-affecting
merges — no stale screenshots, ever.
